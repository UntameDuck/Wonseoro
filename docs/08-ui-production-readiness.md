## 왜 하는가

지금 화면은 동작은 하지만 **개발자가 개발자에게 하는 말**이 섞여 있다. 몇 가지 예를 들면 이렇다.

- 접수 홈 맨 위에 "이 서비스의 구조 — 공통원서·대학검색·내 원서는 중앙에서 제공하지만…" 이 뜬다.
- 본인 확인 칸에는 "개발 단계에서는 … 개발 시드 지원자는 식별자 `44444444-…`, 토큰 `subj-dev-0001` 입니다" 가 있다.
- 모든 화면 바닥글이 "최종 접수 여부는 각 대학 서버가 원본으로 관리합니다" 라고 설계를 설명한다.
- 그 밖에 `양식 버전 cfg-2027-v1`, `적용 마감정책 2027-early-v1`, `EARLY · CSE`, `FINALIZED_COMMIT_BEFORE_DEADLINE` 같은 내부 값이 그대로 보인다.
- 보존기간 근거에는 `v1.0 §9`·`v1.1 §B17 — 불변 기록 (D-35)` 처럼 설계 문서 번호가 찍힌다.

코드 주석처럼 읽히는 이 글을 걷어내고, 그 자리를 지원자·입학처 담당자가 읽을 말로 채우는 것이 이 작업이다.

**디자인은 바꾸지 않는다.** 배치·색·컴포넌트는 그대로 둔다. 바꾸는 것은 다음 넷이다.

- 화면에 보이는 글
- 표기
- 빠진 상태: 불러오는 중, 없음, 오류
- 노션 첨부 와이어프레임(`docs/spec-assets/krds-wireframe.html`)에는 있는데 화면에 빠진 요소

화면에 보이지 않는 코드 주석은 대상이 아니다.

## 무엇을 "코드 설명 같은 문구" 로 보나 — 판정 기준

| 범주 | 뜻 | 예 |
|---|---|---|
| **가. 설계·구조 설명** | 시스템이 어떻게 짜였는지 설명한다. 사용자가 할 일과 무관하다 | "이 서비스의 구조", "원본은 대학 서버", "중앙 조회 기준 시각" |
| **나. 설계 문서·태스크 번호** | `§`·`v1.0`·`D-N`·`T-Mx-yy`·"기술설계서" | 보존기간 근거, 운영 거절 문구의 `T-M5-10` |
| **다. 내부 값** | 영문 대문자 코드·UUID·버전 문자열·JSON 경로·키 ID·UTC ISO 원문 | `EARLY · CSE`, `OPEN`, `cfg-2027-v1`, `forms.EARLY.properties.gpa`, `2026-09-30T14:15:01.926Z` |
| **라. 개발 전용 안내·입력** | 개발·시연에서만 맞는 말과 입력칸 | 시드 지원자 값, "가명 토큰", "개발용 환경변수 정책", 담당자 ID 입력 |
| **마. 기술 원문 오류** | 검증기 영문, HTTP 상태 번호, JS 파서 오류, 헤더 이름 | `must have required property 'highSchool'`, `업로드에 실패했습니다 (403)` |
| **바. 운영 수준 결함** | 위 범주는 아니지만 운영에 그대로 내보낼 수 없는 것 | 날짜 없는 마감 시각, 불러오는 중에 뜨는 "없음" 경고, 영문 기본 404, 인쇄에 메뉴가 함께 찍힘 |

## 함께 발견한 결함 — 증적의 감사 체인 거짓 "끊김" (D-62)

증적 캡처([26](screenshots/admin/26-evidence.png))를 점검하다 찾았다. 정상 흐름으로 만든 원서인데 **"감사 체인이 끊겨 있습니다 — 이 증적을 그대로 쓸 수 없습니다"** 가 떴다.
같은 화면의 타임라인에서는 결제 시작(`PAYMENT_INTENT_CREATED`)이 접수 완료 **뒤에** 온다. 기록 순서와 시각 순서가 어긋났다는 뜻이다.

코드에서 찾은 원인은 둘이다.

- 원서 체인은 시각을 `serverNow()`로 찍는다. 그런데 D-61 이후 시계 offset 이 10초마다 측정값으로 통째로 바뀌어 시각이 뒤로 갈 수 있다.
- 원서 체인에는 시스템 체인에 있는 장치 둘이 없다. 하나는 "직전보다 반드시 뒤 시각"이고, 다른 하나는 잠금이다.

화면 문제는 아니지만 분쟁 증거를 쓸 수 없게 만드는 결함이라 먼저 고쳤다(✅ 2026-10-01). 재현 시험 3개를 만들었고, 고치기 전 코드에서 셋 다 실패했다. 고친 내용은 원서 행 잠금·직전보다 뒤 시각이고, 검증은 앞 해시 연결을 따라간다 — [불일치 대장 D-62](02-spec-discrepancy-register.md#d-62-원서별-감사-체인이-멀쩡한-기록을-끊김으로-판정한다--시각-역전동시-기록-).

## 대상이 아닌 것

- **코드 주석.** 화면에 보이지 않는다. 다만 화면 문자열 안에 설계 번호를 쓰지 않는다는 규칙은 문구 검사로 건다.
- **인라인 스타일을 CSS 로 옮기는 것.** 보이는 결과가 같다. 이번 범위가 아니다.
- **배치·색·컴포넌트 모양 변경.** 와이어프레임에 있는데 빠진 요소(U-55~U-58)만 더한다.
- **본인확인·관리자 SSO 자체.** T-M5-02·T-M5-10 이 맡는다. 이 작업은 그 자리를 비워 두고 개발 입력을 가두는 데까지다.
